# Development history

These sprint briefs, review requests, handoffs and hotfix notes record earlier development decisions. They are historical documents, not current work instructions or the final account of Study 1. For the paper and retained research evidence, use the [Study 1 release](https://github.com/0Pulkit0/Multi-Agent-Workspace/releases/tag/study-1-v1.0.0).

The documents listed below were relocated without changing their bytes. Their original wording, line numbers, dates and historical code/path references are preserved. Filenames and commands inside them refer to the repository layout at the time; use this table to locate moved files. References to later work or local data do not imply those artifacts are present in this checkout.

The D-1 restatement precommitment belongs with the [experiment protocol](../../eval/prereg/), because addenda L and M cite it. It is supporting provenance, not itself an addendum; its text says so. No executable code opens its old root path. The original long README is retained as the [pipeline guide](../PIPELINE.md); run its example commands from the repository root. Some of its implementation and evaluation descriptions are historical and are superseded by the paper's account.
